# FIRE 网页小程序产品规格

状态：已在 `codex/fire-integration` 实现；验收证据与未验证边界见 [交付验收](acceptance.md)。

## 1. 产品目标

帮助中国用户以个人或家庭为单位，明确退休所需资金、按现状预计的达标时间，以及为了在希望年龄退休需要增加的每月净投入。通过引导式输入和实时图形，解释结果为何变化。

默认人民币计价、按今天购买力显示；支持切换各时间点的名义金额。所有结果依赖明示假设，不称为保证可退休，也不提供未经校准的成功概率。

## 2. 三个主要问题

1. 维持我规划的生活，到退休时需要多少钱？
2. 按当前资产、收入和未来生活变化，预计何时满足退休条件？
3. 若想在指定年龄退休，今天起每月还需增加多少可投入净结余？

追加月投入是税后、支付生活等开销后真正留下的钱。它可以来自增收或减支，不等同于必须增加的税前工资。退休后保留的兼职收入属于另一项输入，不与退休前追加投入混用。

## 3. 使用场景与资料边界

- 每份方案使用同一统计范围：个人或家庭。
- 当前未婚可只输入现在的生活状态，不自动添加婚育假设。
- 未来结婚、生育、子女独立等可以设为人生节点，替换阶段生活费。
- 家庭范围不能因添加婚育节点而自动增加伴侣收入或资产，需显式输入。
- 当前收入、资产等个人数据默认空白；提供独立标识的示例方案用于体验。
- 用户可以明确填零；空白不代表零。缺少计算必要信息时显示待完善项目。

## 4. 六步引导

| 步骤 | 输入与交互 | 图形与即时反馈 |
| --- | --- | --- |
| 生活与时间 | 当前年龄、希望退休年龄、规划终点；当前和退休生活费，分刚性/弹性 | 退休时间轴、年度支出规模 |
| 现在的基础 | 税后收入、收入增长；现金和各类投资；房产、负债与还款计划 | 现有资产柱、配置比例、月度结余 |
| 未来变化 | 人生节点、阶段完整预算、一次性大额支出；必要时添加收入变化 | 时间轴标记、预算阶梯、事件资金缺口 |
| 保障与收入 | 购买/不购买社保医保；各方案缴费、养老金、医疗自付；其他净收入的起止时间 | 两个方案对比、未来收入与支出带 |
| 投资假设 | 各资产配置、收益情景、通胀、初始提取率、现金缓冲、冲击幅度 | 组合收益假设、三情景路径与压力测试 |
| 退休路径 | 查看解释、调整目标、复制方案、对比、导出 | 资金曲线、目标线、达标时间和追加月投入 |

不强迫用户每次完成全部六步。首次按步骤收集，后续可以直接跳回修改；高级参数折叠。未完成必要资料时，已有数值可用于局部反馈，完整结论保持待完善状态。

## 5. 人生节点与预算

- 使用年龄或对应年月定位；按月计算。
- 每个生活费节点填写生效后的完整预算，而非默认增量。
- 例如：现在每年 8 万、结婚后 14 万、孩子出生后 20 万；生效后替换上一阶段。
- 婚礼、购车等一次性费用按单独事件计入，不再包含于同一阶段的年度生活费。
- 未来预算按今天物价填写，再由模型统一考虑通胀。
- 明确区分退休前与退休后预算：人生节点可分别更新两者，避免推迟退休时误用原目标年龄的退休预算。
- 支持添加、改名、删除、拖动时间，以及精确填写年龄/日期；同月相互冲突的完整预算应合并或提示处理，不静默择一。
- 调整希望退休年龄，只移动退休安排；婚育、养老金等固定人生节点保持各自时间。

## 6. 社保医保方案对比

对比从现在起继续购买与不再购买两种方案，保留已有缴费记录和权益，不将不购买解释为没钱购买。

| 内容 | 购买方案 | 不购买方案 |
| --- | --- | --- |
| 未来养老/医保缴费 | 用户填写金额、起止时间与增长方式 | 从现在起不再计该项缴费 |
| 养老金 | 用户填写预计起领年龄、净金额和增长方式 | 用户填写已有权益对应的待遇；不自动清零 |
| 医疗自付 | 独立预算，可为非零 | 独立预算，不自动估计疾病损失 |
| 保障说明 | 仅描述用户录入的参保安排 | 标明此方案未继续缴费；已有待遇是否有效由用户核对 |

首版不根据地区、缴费年限自动推算资格、医保报销率或养老金。两方案待遇估计未填写时分别显示待完善，不能输出具有确定性的优劣排序。

税后工资作为实际到手收入。如果在职养老/医保个人缴费已从工资扣除，应标明已扣，不能再次扣减；离职后自行支付的缴费按单独支出处理。商业保险是其他支出，不因停止社保医保而自动删除。

## 7. 资产和收入

- 按现金、股票/基金、债券/存款、其他可投资资产记录当前金额，自动展示当前配置。
- 当前持仓金额与未来目标配置分开；修改目标比例不凭空改变现有总资产。
- 自住房单列，不直接计入可提款资金；房租、房贷、维护开销进入对应支出。
- 出租房默认提供净租金，房屋估值不再次加入可提款本金；首版不自动安排房产出售。
- 债务记录余额以及明确的还款现金流和结束时间；不在初始资产扣除全额本金后又重复扣同一还款。
- 分红、债券利息等属于投资组合总回报，不重复添加为组合外收入。
- 其他收入可设置金额、起止时间、通胀增长或固定名义金额；未明确延续的工作工资在退休时停止。

## 8. 默认假设

| 参数 | 默认值或处理 |
| --- | --- |
| 规划终点 | 85 岁，可改 |
| 通胀 | 年化 2%，可改 |
| 初始提取率 | 3%，可改；独立于收益率 |
| 现金缓冲 | 未来两年经常性生活费，可改 |
| 工资增长 | 实际 0%，即名义随通胀增长；可改 |
| 退休本金 | 允许逐步消耗，不默认遗产要求 |
| 压力测试 | 退休首月股票 -35%、债券 -5%、现金不受冲击 |

收益为可修改的名义总收益演算假设，包含分红和利息、已扣常规成本：

| 资产 | 保守 | 基准 | 乐观 |
| --- | ---: | ---: | ---: |
| 现金 | 0.5% | 1.5% | 2% |
| 债券/存款 | 1% | 2.5% | 4% |
| 股票/基金 | 2% | 6% | 8% |

其他资产须填收益假设或明确确认按零收益估计。不存在默认投资配置建议，也不连接行情或推荐具体证券。

## 9. 结果页

结果区先展示资金曲线，再展示以下五个指标：

1. 退休目标总资金，拆出投资本金与现金缓冲。
2. 按现状预计达标年龄及距今时间。
3. 希望退休年龄时预计资产，以及与该时点所需资金的差额。
4. 从现在起还需增加的每月净投入。
5. 购买与不购买社保医保两个方案的对应差异。

下方展示：

- 从现在到规划终点的资产路径和收支变化。
- 退休起点、婚育节点、大额支出和养老金起领标记。
- 提取率参考目标与全程资金需求的构成和来源。
- 保守/基准/乐观各自结果；基准是主要显示情景。
- 压力测试中的最低余额、首次资金不足时间和资金差额。
- 手动目标与系统目标的对照。
- 当前方案假设与缺失资料，说明结果变化的关键原因。

不把未知、已达标、规划期内未达标、临时输入未完成和计算数值错误混为零。退休前即出现的资金透支也必须显示，不能只检验退休后的终点余额。

压力测试保持原定消费，不自动减支、延后退休或提高回报。动态提款护栏不在首版范围；保留弹性支出数据供用户主动比较减支方案。

## 10. 视觉与交互

- 基调：炭黑背景、白灰细线、暖橙色焦点；有足够对比度和可读字号。
- 主视觉：叠层资产柱、目标高度线、人生时间轴与资金曲线，数值变化反映于图形。
- 桌面：左侧引导输入，右侧资金曲线位于指标汇总之前，随页面滚动保持在结果区顶部可见；手机保持自然单列，不固定图表遮挡输入。
- 曲线吸附最近月份，十字线在横轴显示年龄、纵轴显示精确到元的余额；读数同时提供年月、目标金额和当前购买力／名义口径。支持鼠标、触屏点按和键盘左右逐月查看。
- 手机：单列步骤，保留精简结果摘要和清晰的前后导航，不遮挡输入与键盘。
- 滑块和精确数字输入双向同步；支持键盘。拖动人生节点也可用数字输入完成。
- 滑块范围只是快捷操作范围，精确数字输入不被滑块上限截断。
- 输入未完成或无效时保留最后一次有效结果并清楚标记，不继续显示为已使用新值的结论。
- 动效用于表现数字、资产高度和位置的变化；减少动态效果设置下立即或平滑简化更新。
- 退休生活提示采用暖米白背景，作为自选阅读内容，不增加强制问卷步骤。

## 11. 方案与数据

- 本地自动保存，多方案命名、复制和比较。工具栏可修改当前方案名称（去除首尾空白，不接受空名称，最多 500 字符），结果与文件名使用同一名称。
- 删除当前方案前显示名称并确认；有剩余方案时切换相邻方案，仅当删除后无方案时自动建立空白方案。清理被删方案的编辑、评估缓存与比较状态，保存后刷新不恢复被删内容。
- 结果图片导出为 PNG：包含方案名称、当前保障／收益情景和金额口径、资金曲线、关键指标、目标构成、压力测试、六情景比较和结果边界；排除输入区、工具栏、交互控件、悬停读数和月度明细。计算中或输入未完成时暂停导出；从点击时的结果副本生成，避免混入后续编辑。
- JSON 导出/导入保留版本、输入和假设；导入先校验结构及数值。
- Markdown 报告包含关键输入、默认假设、结果、社保医保比较和压力测试。
- 无账号、无云同步、无外部分享链接。个人资料不需要上传服务端。
- 示例明确标识；导入和重置不得静默覆盖已有方案，先保留副本或由用户明确选择替换。
- 本地存储不可用或容量不足时显示未保存状态，并提供导出。

## 12. 实现与交付

React + TypeScript + Vite；计算逻辑独立于界面，SVG 图形和轻量动效。先交付可本地预览网页。

实现完成需要以下证据：

- 计算检查覆盖阶段预算替换、养老金晚于退休、大额事件、社保双方案、资产和收益不重复、现金内部划转守恒、缺口反推与不可达情况。
- 真实浏览器检查桌面与手机，滑块/精确输入/节点时间联动、六步导航、保存恢复、导入导出及方案比较。
- 画面检查符合视频参考、中文清晰、图形随输入改变、无明显遮挡或横向溢出。
- 提供启动方法和已验证/未验证事项。

## 13. 首版范围之外

自动推算社保政策、实时行情、个股推荐、历史回测或蒙特卡洛成功率、自动动态提款护栏、账户同步及外部发布。
