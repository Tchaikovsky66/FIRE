## 已明确要求

- 根据本目录的视频总结，设计一个 FIRE 规划网页小程序。
- 通过引导式流程收集指标，包括预计年支出、大额支出、资产分配、预计被动收入、退休时间和退休资金目标等。
- 计算在现有基础上所需的资金、时间，以及为了达到目标还需增加多少收入。
- 参考视频的画面风格。
- 部分指标同时支持拖动滑块与点击输入；指标变化时，图形与计算结果同步变化。
- 本次采用 grill-with-docs 方式讨论，随确认结果更新术语与设计文档。

## 已确认的产品决定

用户于 2026-10-20 回复“按推荐来”，确认第一轮五项推荐：

1. 面向中国用户，人民币计价；每份方案对应个人或家庭，收入、资产和支出统一按该范围统计。
2. 同时计算“按现状预计何时达标”和“指定退休年龄需要增加多少每月净投入”。退休所需资金默认计算，可用手动目标作比较。增收先表达为税后且能存下来的金额。
3. 第一版采用透明基础测算、保守/基准/乐观情景、退休初期大跌压力测试。不输出没有依据的退休成功概率。投资收益率与初始提取率独立设置；初始提取率默认 3%，收益假设默认见第四轮。
4. 视觉以炭黑背景、白灰线稿、橙色光点、叠层资产柱和时间轴为主。桌面左侧引导输入、右侧实时图形；手机保留结果摘要。滑块和数字输入双向同步，资产柱、目标线和达标年份联动。退休生活部分可采用暖米白背景。
5. 响应式网页，无需登录，本地自动保存，可导出和重新导入方案。首版重点是计算、交互与方案比较。

用户第二轮回复确认并修正：

6. 金额默认按今天购买力显示，可切换未来名义金额；通胀默认 2% 且可修改。
7. 规划终点默认 **85 岁**，允许修改；允许逐步使用本金，不默认要求遗产。初始提取率以可调的 3% 作估算锚点，并检查退休期间的现金流。
8. 当前与退休后的生活费分开；按税后收入扣除当前生活费、债务付款等，计算每月实际可投入结余。用户目前未婚，明确要求支持在未来结婚、生育等节点重新输入生活费，后续按新支出计算；不能将当前单身开销外推到整个规划期。节点完整预算替换方式已在第三轮确认。
9. 资产按现金、股票/基金、债券/存款、其他投资分别输入金额并生成比例。房产、债务单列，避免现金缓冲与投资本金重复计算。
10. 组合外收入逐项记录来源、净金额、起止时间与通胀增长方式。组合内分红利息只计入总回报一次，养老金和兼职按实际设定的开始时间入账。社保医保支持两个对比方案：购买社保医保，或不购买社保医保；这不是“缴不起”的现金流告警。两种方案分别计算支出、退休后收入和保障说明。
11. 大额支出按事件和发生时间扣除，区分退休前后。退休经常性支出分刚性、弹性；默认单列两年退休生活费的现金缓冲，允许调整，补充规则见第四轮。

用户第三轮回复“都按推荐来”，确认：

12. 未来人生节点填写变化后的完整生活费，从节点时间起替换原预算；一次性费用另记。节点可拖动时间、修改、删除，不预设必然结婚或生育。
13. 不同资产类别使用可调收益假设，按配置比例计算组合回报；保守/基准/乐观情景驱动资产曲线与达标时间同步变化，并展示假设。
14. 提取率参考目标与覆盖至规划终点的全程资金需求分别计算，系统目标需同时满足两者。现金缓冲单列且不重复计算，手动目标只用于对照。
15. 社保医保比较从现在开始继续购买与不再购买，保留已有缴费权益。缴费金额、期限、养老金起领年龄与金额由用户提供，不按地区自动推算待遇。未购买方案可填写已有养老金；医疗自付预算独立设置，已购买不代表自付为零。未填写待遇标为待完善，不自动认定为没有待遇。

## 设计树与待决事项

### 第一轮：已完成

1. 使用者与计算单位：个人还是家庭、币种和主要使用地区。
2. 核心目标：按现状推算达标时间、按期望日期倒推追加投入，以及手动资金目标的角色。
3. 结果可信度表达：假设条件下的测算、压力情景或概率模拟。
4. 视觉基调：视频中的暗色线稿、橙色光点、资产堆叠与时间轴如何转为可操作界面。
5. 产品边界：响应式网页、本地保存、账号、云同步及分享需求。

### 第四轮：默认值、判定与交付，已确认

用户回复“都按推荐来”，确认第四轮 Q16—Q20。以下为对应的细化计算与交付约定，已整合到整体规格供收口核对。

16. 默认收益为可编辑的演算假设：名义、包含分红利息、已扣常规成本。现金：保守 0.5% / 基准 1.5% / 乐观 2%；债券/存款：1% / 2.5% / 4%；股票/基金：2% / 6% / 8%。其他投资要求显式填写其假设或确认按零收益估算。这些不是行情预测；不自动推荐资产比例或证券。工作净收入默认实际增长 0%，名义随所设通胀增长；高级设置可调。
17. 按月推进时间轴。提取率参考投资本金以退休后首个完整 12 个月的经常性支出净缺口 / 提取率计算，下限为零；养老金按实际起领时间进入。另用相同模型反求覆盖全程的资金。推荐总目标满足参考本金加初始现金缓冲、且通过基准全程现金流；两项取约束更严格者，不将两份本金相加。缓冲初始为随后 24 个月经常性生活费，不含大额事件；从现金支付需求，每年末从投资账户内部划转补足下一缓冲窗口，不能补足时显示缓冲不足，不创造新增资产。参考目标只是一项约束，完整时间轴覆盖未来预算变化与大额支出。达标搜索年龄从现在至规划终点前，既要有退休起点资金，也要全程不透支；若不达标明确显示规划期内未达标。额外净投入按今天购买力、从现在持续至所选退休时间反求，随通胀调整；不默认伴侣带来新收入，退休时结束未明确保留的工作收入。
18. 单列压力测试：候选退休第一个月，股票一次下跌 35%，债券一次下跌 5%，现金不变；随后按选定基准假设继续模拟，不额外叠加该月股票/债券常规回报。冲击参数可改，明确为假设而非历史重演。压力测试不偷偷减少消费，不自动改变用户退休时间；显示资金最低点、首次不足时间以及需要的调整。主结果为基准达标，压力测试结果另标。动态护栏策略留待后续版本。
19. 六步引导：生活与时间 → 当前收入与资产 → 未来人生节点与大额支出 → 社保医保与其他收入 → 资产配置与假设 → 结果和方案比较。基础问题优先，高级参数折叠；允许返回任一步。金额滑块为便捷范围，数字输入可超出滑块上限且不能被静默截断；完整非法输入不参与计算，输入中间态保留最后有效结果并提示待完成；无障碍键盘、移动端与减少动态效果支持。结果展示目标本金、现金缓冲、预计达标年龄、目标年龄缺口、追加月投入及两种社保医保方案差异；支持复制方案比较。
20. 第一版用 React + TypeScript + Vite，独立计算模块，SVG 图形与轻量动效；本地保存并提供 JSON 导入导出、Markdown 报告。先交付可本地预览网页，不含外部发布。验收包含计算边界及事件/收益重复计算检查、真实浏览器桌面手机交互、滑块数字联动和保存恢复。输入资产与收入默认空白，另有独立示例体验，避免将示例当个人资料。完成设计汇总后再由用户确认开始实现。
