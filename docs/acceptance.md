# Workbench 浏览器验收

## 环境与复现

2026-10-21，本地 macOS、Node 22.22.0、Playwright 1.64.1、Chromium 156.0.8078.4。Browser plugin not available；使用仓库内 Playwright 直接运行真实页面、Worker 与浏览器存储，没有替换金融计算。

```sh
npm install
npx playwright install chromium
npm test
npm run build
npm run test:e2e
```

桌面为 1440 × 1000；手机为 390 × 844，并开启触摸及移动设备模拟。浏览器用例在 `tests/browser/workbench.spec.ts`，与 Vitest 的 `tests/**/*.test.ts` 分开收集。

## 已验证

| 验收项 | 实际证据 |
| --- | --- |
| 六步填写与导航 | 从空白输入完成个人方案；前进、后退、直接返回已有步骤，保留输入；六种保障／收益组合输出。 |
| 桌面与移动布局 | 两种视口流程均无页面横向溢出；桌面左右输入／结果，手机单列；已人工检查工作区、结果及图表截图。 |
| 精确输入与快捷滑块 | 工作月收入 200000 超过滑块快捷范围后保持原值；方向键改为 199000；明确 0 有效。 |
| 未完成与快速编辑 | 空白、负年龄分别显示待完善／无效；保留最后有效结果。年龄快速修改 36 → 37 → 35，当前结果及下载报告使用 35。 |
| 可视化联动 | 生活费、资产、收入、通胀修改驱动曲线、纵轴金额、资产条与目标结果更新；人生节点月份、年龄、年月、滑块双向同步；移动退休不移动固定节点；同月预算冲突提示；一次性支出改变曲线。 |
| 状态及中文金额 | 未填养老金只影响对应三个组合，另一保障方案可计算；显示中文单位与“约”；不把未知养老金替换成零。 |
| 键盘与减少动画 | 方向键操作滑块；收入名称逐字输入保持焦点；减少动画偏好下输入框过渡为 0s。 |
| 本地方案与交换 | 复制独立、比较、报告、JSON 导入为新副本、拒绝坏 JSON 与未来版本、刷新恢复，原方案不受副本影响。 |
| 保存失败 | 在真实 Storage 写入处注入配额异常，页面提示失败，内存输入与结果保留，JSON 导出仍含最新输入。 |
| 收入名称稳定性 | 两条同名收入可独立修改金额与删除；JSON 中 ID 不同、名称相同，报告使用名称。旧数据无 label 时兼容显示原 ID。 |
| 手机图表可读性 | 修复固定 760 单位 SVG 缩成约 4.14px 标签的问题；按容器宽度绘制，字体实际约 11px；桌面／手机均断言至少 10.5px。 |

最终集成代码 `bc52654` 执行单元测试 44 条通过（7 个文件），生产构建通过；浏览器完整运行 8 个流程、双视口 16 个用例全部通过，用时约 1.3 分钟。Planning 测试全部穿过公开 `evaluatePlan` 接口，删除旧过渡模拟器与依赖私有实现的重复测试后保留领域行为回归。相对初始基线 `c7b0e7f` 的 `git diff --check` 通过。

输入到有效评估延迟由实际界面指标记录，包含防抖与 Worker 往返：桌面最小输入 119 ms、示例 459 ms；手机视口最小输入 113 ms、示例 465 ms。这是本机观察值，不是性能保证，也不代表低端手机设备表现。

## 评审修复与计算回归

规格与规范两条评审均已复核，原发现全部修复，无剩余阻塞项。复核覆盖：

- 压力测试分别记录名义最低余额、今天购买力最低余额与发生月份，包含同月冲击后、付款后和收益后的低点。
- 养老金默认按今天购买力录入，可明确选择起领月名义金额；两种初始口径与领取后的实际／名义增长共四种组合均有公开计算回归。
- 实际页面与方案比较共用 Session 的 Worker 生命周期；输入修订、方案身份及最后有效结果不会错配。
- 资产、预算替换、一次性费用、已有养老金权益和缴费行为由同一月度模拟器实现，测试经公开评估接口验证。
- 极端通胀下的购买力换算下溢、极端收入增长溢出返回 `numeric-error`，不会伪装为 `search-bound`；正常未达标与付款不足保持独立。
- 两份本地方案可比较完整六种保障／收益组合，未完成计算期间隐藏旧比较结果。

## 未验证与边界

- 未用真实 iPhone／Android 设备，软键盘遮挡、系统字号、浏览器地址栏变化仍待真机检查；触摸模拟不等于真机验收。
- 未验证 Safari、Firefox、屏幕阅读器或完整 WCAG 合规。
- 浏览器流程未强行构造全部稀有求解错误分支；未达标、付款不足、求解错误的数值正确性及全部金额口径，以公开 `evaluatePlan` 的计算测试及规格评审为准。
- 浏览器检查验证界面与实际计算结果相连，不充当独立金融公式校验或投资结果保证。
